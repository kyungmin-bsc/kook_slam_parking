시나리오최소 여유이동구간 접촉초음파 정지 A 보정A 오차B 보정B 오차소요
유효한 것 — 주차·탈출·보정 기동은 실제 solve_perpendicular / solve_parallel / solve_correction 출력을 그대로 실행했고, 후방 초음파는 드라이버 규약(140 초과는 0)까지 재현한 가드를 태웠습니다. 전 시나리오에서 주차·탈출·보정 구간 접촉은 0건입니다. 경로 선택도 실제 passability 판정 결과입니다.
유효하지 않은 것 — 이동 구간은 Nav2가 아니라 제가 만든 격자 경로계획기를 씁니다. 이 계획기는 차량을 반폭 원으로 근사해서 길이 0.61m를 반영하지 못하고, 그래서 좁은 목 진입부에서 차체 모서리가 스치는 표본이 몇 개 남아 있습니다(표의 "이동구간 접촉"). 실제 Nav2 Hybrid A*는 footprint로 계획하므로 이 현상은 나타나지 않습니다. AMCL 위치추정 오차도 넣지 않았습니다.
실차 검증은 아직 없습니다.
