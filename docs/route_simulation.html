이동 구간은 Nav2가 아니라 경유점을 평활화한 경로를 이상적으로 추종한 결과입니다. 실제 Hybrid A*는 다른 곡선을 냅니다 — 이 시뮬레이션이 답하는 것은 “이 통로 폭에 이 차체가 들어가는가”이지 “Nav2가 이 경로를 낼 것인가”가 아닙니다. 주차·탈출 구간은 실제 solve_perpendicular / solve_parallel / reverse_prims 출력을 그대로 실행한 것이라 그대로 유효합니다. 실차 검증은 아직 없습니다.
